# Roamly Schedule

This is the fresh starter UI for Roamly Schedule.

## Run it

From this folder, run:

python3 -m http.server 8000

Then open:

http://localhost:8000

## Current version

- Modern blue/purple tech UI
- Animated landing page
- Create New Trip
- Trips saved in browser localStorage
- Continue existing trips
- Roamly.Jr. chat interface
- Schedule tab
- Smart Plan placeholder
- Responsive layout

## Next build

The demo chat currently uses placeholder replies. The next step is a secure Node.js backend that connects Roamly.Jr. to a real language model and then gives it controlled Roamly tools for place search, distance, schedule changes, and itinerary organization.
